Guia Básico de Git e GitHub

Git é um sistema de controle de versão que permite gerenciar alterações em arquivos. GitHub é uma plataforma online que hospeda repositórios Git e facilita a colaboração entre desenvolvedores.

Para começar, é necessário instalar o Git no computador e configurar seu nome e e-mail com os comandos git config --global user.name e git config --global user.email. Depois, você pode criar um repositório com git init, adicionar arquivos com git add e salvar alterações com git commit.

Para enviar seu projeto ao GitHub, use o comando git push após conectar ao repositório remoto com git remote add origin. Esses comandos são essenciais para compartilhar seu código e trabalhar em equipe de forma eficiente.
